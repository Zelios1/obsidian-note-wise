# Obsidian OpenAI Auto Category and Tags Plugin

Automatically categorize and tag your notes using the power of OpenAI. This plugin analyzes your notes, including titles, frontmatter, and content, to suggest relevant tags, streamlining your note organization process.

## ⚠️ Disclaimer

**Warning**:  
This plugin **modifies your notes** and can **delete or overwrite existing data** in the metadata section.

- **Use with caution**: It is highly recommended to test this plugin on a **copy of your notes** to ensure it works as expected and does not disrupt your workflow.
- **Backup your data**: Always maintain a backup of your notes before using this plugin.

Example of added metadata:

```yaml
---
created: 2025-01-09T18:49:17.264Z
wiseupdated: 2025-01-09T18:49:17.265Z
category: interview
tags:
  - work
  - backend
---
```

## Features:

- Auto Classification: Effortlessly classify tags based on your note's content.
- Flexible Settings: Configure API keys and select preferred models easily.

## How to Install

Clone this repository.
Copy the plugin files to your .obsidian/plugins folder.
Enable the plugin in the Obsidian settings.

## Usage Instructions:

Enter your OpenAI API key in the settings tab.
Use the provided commands to classify tags from various sections of your notes.
This plugin is ideal for organizing research papers, books, or any notes requiring structured tagging. Enhance your productivity and keep your vault organized with automated tagging.
